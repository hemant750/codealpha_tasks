# Hotel Reservation System

## About the Project
The Hotel Reservation System is a Java-based console application designed to manage hotel room bookings.

## Features
- View all hotel rooms and their availability
- Book a hotel room
- View all booking details
- Cancel an existing booking
- Calculate the total bill based on room price and number of days
- Save and load booking records using file handling

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Scanner

## How to Run
1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal in that folder.
4. Compile the program using:

   `javac HotelReservationSystem.java`

5. Run the program using:

   `java HotelReservationSystem`
