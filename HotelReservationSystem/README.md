# Hotel Reservation System

## About the Project
The Hotel Reservation System is a Java-based console application that helps users manage hotel room bookings easily.

## Features
- View all hotel rooms
- Check available rooms
- Book a room
- View booking details
- Cancel a booking
- Calculate the total bill based on room price and stay duration
- Save and load booking records using file handling

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Scanner for user input

## How to Run
1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

   `javac HotelReservationSystem.java`

5. Run the program:

   `java HotelReservationSystem`
