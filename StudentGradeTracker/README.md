# Student Grade Tracker

## Project Description
Student Grade Tracker is a console-based Java application that helps manage student marks and academic performance. It calculates total marks, percentage, and grades automatically.

## Features
- Add multiple student records
- Calculate total marks and percentage
- Assign grades automatically
- View all student records
- Search students by name
- Calculate class average
- Find highest and lowest scoring students
- Save student records in a text file
- Load saved records when the program starts

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling
- Scanner for user input

## How to Run
1. Install the Java Development Kit (JDK).
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. Compile the program:

   `javac StudentGradeTracker.java`

5. Run the program:

   `java StudentGradeTracker`
